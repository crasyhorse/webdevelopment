# Mini-Exercise 01 — First CSS Rules

**Starting point:** The final semantic Task Manager from the HTML workshop. This exercise intentionally requires only simple CSS and descriptive class names, not Flexbox, Grid, media queries, box sizing or the cascade in depth.

## Tasks

1. Open `index.html` and confirm its external stylesheet link points to `styles.css`.
2. In `styles.css`, set a different background color on `body`.
3. Choose a readable text color for `.task-title`.
4. Style `.submit-button` with a background color and contrasting text color.
5. Add a CSS comment explaining the purpose of a rule.
6. Open DevTools, inspect the heading, and identify the source file and winning `color` declaration.

## Explore color values

- Apply one color with hexadecimal notation (e.g. `#245f9f`) and another with `rgb()` or `hsl()`.
- Change a background to `rgba()` or `hsla()` with `0.5` alpha and observe what shows through.
- Check that foreground and background remain readable; compare the computed color in DevTools.

## Explore

Try deliberately misspelling one CSS property. What happens to the other declarations? Fix the typo and check DevTools again.
