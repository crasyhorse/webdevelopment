# Quiz 02 — Logical Padding Properties

## Questions

1. What is the difference between **physical** padding properties such as `padding-left` and **logical** properties such as `padding-inline-start`?

2. In a normal horizontal **left-to-right** layout, which physical side does `padding-inline-start` affect? What about **right-to-left** text?

3. For horizontal writing, which physical sides do `padding-block-start` and `padding-block-end` affect?

4. A Task Manager card must have **16px of space at the beginning of the text direction**, regardless of whether the interface is left-to-right or right-to-left. Which single CSS declaration would you write?

5. What changes about `padding-inline-start` and `padding-block-start` when the writing mode changes from `horizontal-tb` to `vertical-rl`?
