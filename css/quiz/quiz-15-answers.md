# Quiz 15 — Answers

## 1. What is a tint?

A tint is created by mixing a base color with white, making it lighter.

## 2. What is the difference between a shade and a tone?

A shade is created by mixing a base color with black, making it darker. A tone is created by mixing a base color with neutral gray, making it more muted.

## 3. What is a monochromatic color scheme?

A monochromatic color scheme uses variations of a single hue, for example blue with its tints, shades and tones.

## 4. What is the difference between a monochromatic and a complementary color scheme?

A monochromatic scheme uses one hue. A complementary scheme uses two opposing hues on the color wheel. On the CSS HSL hue circle, complementary hues are 180° apart, for example blue at 217° and orange at 37°.

## 5. What other color harmonies exist?

- **Analogous:** neighboring hues on the color wheel.
- **Split-complementary:** a base hue and two hues on either side of its complement.
- **Triadic:** three hues equally spaced around the wheel.
- **Tetradic:** four hues forming two complementary pairs, including square and rectangular arrangements.
