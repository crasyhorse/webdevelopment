# Group 1 — What is Flexbox and what is it used for?

## Starting point

A toolbar with three actions. Open `index.html` in your browser and edit `styles.css`. No other group’s work is needed.

```html
<div class="toolbar"><div class="item">Save</div><div class="item">Edit</div><div class="item">Delete</div></div>
```

```css
.toolbar { /* Add your declaration here. */ }
.item { padding: 12px; }
```

## Experiments

1. Open `index.html` in your browser and observe how the three blocks are arranged before making changes.
2. Add `display: flex` to `.toolbar`. Compare the result with the original.
3. Resize the browser. Try adding a fourth action in the HTML.
4. Inspect `.toolbar` in DevTools and enable its Flexbox overlay if available. Identify the container and its direct children.

## Present your answer

Explain what Flexbox does, which elements become flex items and give two practical use cases.
