# Quiz 18 — Custom Properties

## Questions

1. What happens to a declaration using `var(--missing)` when `--missing` is never declared and no fallback is given?
2. When exactly is the fallback argument of `var()` used?
3. Can a custom property be declared on any selector, or only on `:root`? What decides which declaration wins?
4. Why does a custom property declared on `:root` reach every element on the page without any additional declaration?
5. How could you use custom properties to give one component a different accent color than the rest of the page — without a modifier class for every color?
