# Exercise 05 — Reference Solution

The reference solution retains the BEM names and semantic Task Manager markup from Exercise 04.

- A universal `border-box` rule simplifies component measurements.
- A fluid page wrapper combines percentage-based sizing, `max-width`, and automatic margins.
- List items use padding and margins, preserve variants, and wrap unusually long text.
- Form controls have predictable full widths and comfortable minimum heights.
- No fixed content heights or overflow clipping are needed.

Open `index.html` and inspect the boxes in DevTools. Try narrow viewports and 200% browser zoom.
