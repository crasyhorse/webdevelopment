# Demo 03 — Three Ways to Add CSS to HTML

Open `index.html` through a local HTTP server.

1. Locate the external CSS `<link>` in the HTML head.
2. Activate the internal `<style>` override for the title and observe the result.
3. Add an inline `style="color: ..."` attribute to the same title.
4. Inspect applied and crossed-out declarations in DevTools.
5. Remove the inline style and the internal override. Contrast ordinary inline styles with an `!important` override (covered later).

The demonstration assumes ordinary author declarations; importance, layers and other cascade steps can change precedence.
