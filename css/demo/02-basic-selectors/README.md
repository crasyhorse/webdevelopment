# Demo 02 — Basic CSS Selectors

Open `index.html` with a local HTTP server and inspect the matching rules in DevTools.

1. Change `h2` to `li` and observe a different set of elements.
2. Inspect `.task-item` and confirm both list elements match.
3. Inspect `#tasks`; identify the unique ID in HTML.
4. Observe the universal `*` selector and why it adds no specificity.
5. Prefer descriptive classes for component styling rather than depending on IDs.
