# Demo 07 — BEM in DevTools

Serve the repository root locally and open `css/demo/07-bem/index.html`.

1. Inspect the `.task-list` **block** and `.task-list__item` **element**.
2. Compare an ordinary item with `.task-list__item--high-priority` and `.task-list__item--completed`.
3. In DevTools, remove and re-add a modifier class. The base styles remain because the base element class is still present.
4. Inspect `.task-form` and `.task-form__submit` to see a second block.
5. Tab to the submit button. Confirm the visible `:focus-visible` outline and inspect its CSS.

All files use plain HTML and CSS; no JavaScript, SCSS or CSS framework is required.
