1. learn how fixed, fluid and responsive layouts differ.
2. discover how **media queries** and content-driven breakpoints adapt layouts.
3. become familiar with intrinsically responsive layouts built from Flexbox and Grid.
4. explore CSS math functions for fluid sizing.
5. get to know **container queries** as a way to adapt reusable components.
6. practice testing responsiveness, usability and accessibility.
