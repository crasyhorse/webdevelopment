# Exercise 13 — Responsive Components

1. Reuse a Task Manager summary component in two panels.
2. Compare viewport and container responsiveness.
3. Establish named query containers and adapt each component.
4. Resize one panel independently and inspect the result.
5. Experiment with named and unnamed query contexts.
6. Test both instances at the same viewport width.
