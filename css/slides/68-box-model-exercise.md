# Exercise 05 — Size & Space the Task Manager

1. Start from the **completed Exercise 04** Task Manager.
2. Use a global `box-sizing: border-box` rule.
3. Give the task form and task cards consistent **padding**, **borders**, and **margins**.
4. Set sensible maximum widths and minimum heights without fixing content height.
5. Make inputs use the available width without overflowing their containers.
6. Test a long task description, increased text size, and a narrow viewport.
