# Flexbox or Grid?

| Flexbox | Grid |
|---|---|
| Primarily one axis | Rows and columns together |
| Navigation, buttons, card internals | Dashboard and card collections |
| Items flow and wrap independently | Items align to shared tracks |

**Combine both:** Grid for the dashboard, Flexbox for the controls inside it.

<!--
- Neither replaces the other. A flex item can itself be a grid container and vice versa.
