# Exercise 04 — Refactor the Task Manager with BEM

1. Start from the **completed Exercise 03** Task Manager.
2. Identify reusable blocks: Task Manager, task list, and task form.
3. Rename the relevant classes using **block**, **element**, and **modifier** conventions.
4. Mark one task as **high priority** and another as **completed** using modifiers.
5. Update CSS selectors and verify that styles, form semantics, and keyboard focus still work.
