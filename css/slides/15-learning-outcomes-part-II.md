1. learn to select HTML elements using combinators and attribute selectors.
2. discover how pseudo-classes and pseudo-elements differ and when to use them.
3. understand how the cascade determines which declaration wins when CSS rules conflict.
4. learn how specificity, `!important`, source order, and inheritance influence styling.
5. practice identifying and resolving conflicting CSS declarations using DevTools.
