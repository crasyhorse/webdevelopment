# The CSS Box Model

<img src="/images/box-model-diagram.svg" alt="The CSS box model from the inside out: content, padding, border, and margin, each shown as nested rectangles." class="w-full mx-auto block" style="max-height: 55vh; object-fit: contain;" />

- **Content** holds the text or image; **padding** creates inner space; **border** surrounds padding; **margin** separates neighboring boxes.
