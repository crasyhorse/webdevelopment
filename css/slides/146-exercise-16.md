# Exercise 16 — Design Tokens

1. Extract color, spacing and typography values into raw and semantic tokens.
2. Re-scope one token for a single component variant.
3. Add a dark theme by re-declaring the tokens under `[data-theme="dark"]`.
4. Verify contrast in both themes and keep the responsive layouts intact.
