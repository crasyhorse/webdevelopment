# Exercise 06 — CSS Units

1. Start from the **completed Exercise 05** Task Manager.
2. Replace a fixed card width with a **percentage width** plus a sensible **max-width**. Resize the viewport and compare the result.
3. Add a **banner** or **info panel** sized with `vw` and `vh`. Resize the browser to see which dimension changes.
4. Create a **small** and a **large** button. First use `rem` for their padding, then switch to `em` and compare the proportions.
