# Exercise 02 — Selecting elements

1. Continue with the Task Manager from **Exercise 01's solution**.
2. Target a task list item with a **child or sibling combinator**.
3. Highlight `input[required]` and one additional attribute selector.
4. Experiment with **`:hover`, `:focus-visible` and `:first-child`** to discover how pseudo-classes select states and structure.
5. Use **`::before`, `::after` and `::first-letter`** to style generated content and parts of elements. Inspect the differences in DevTools.
