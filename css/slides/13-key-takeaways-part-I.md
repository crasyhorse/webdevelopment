- **HTML** provides structure and meaning; **CSS** controls presentation.
- Browsers apply **default styles** before we add our own.
- CSS rules consist of **selectors** and **declarations**.
- CSS colors can use **hex, RGB(A), and HSL(A)** values.
- **Type, class, and ID selectors** target elements; descriptive classes make styles easy to maintain.
- **DevTools** helps us inspect applied and ignored rules.
