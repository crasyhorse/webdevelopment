# Exercise 07 — Box Model & Overflow

1. Start with the **Exercise 06 solution**. Size the Task Manager's task sections using **padding, borders, margins and maximum widths**.
2. Constrain the task list with `max-height`; compare **overflowing items** with `overflow-y: auto` and explain why `hidden` is unsafe.
3. Make the large task **preview image** responsive with `max-width: 100%` and `height: auto`.
4. Give **form inputs and selects** `width: 100%` with `box-sizing: border-box`, padding and a usable minimum height.
