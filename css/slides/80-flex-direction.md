# Flex Direction — Main and Cross Axes

<div>
  <img src="/images/flex-axes.svg" alt="Four directions: row, row-reverse, column, column-reverse with main and cross axes." class="block mx-auto w-full" style="max-height: 38vh; object-fit: contain;" />
</div>

- `flex-direction` sets the main axis; the cross axis is perpendicular.
- `row` follows the inline axis; `column` follows the block axis.
- Reverse values change visual order, not the HTML or keyboard order.
