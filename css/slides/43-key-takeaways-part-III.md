- **BEM** is a CSS class-naming convention — not new CSS syntax or a framework.
- **Blocks** are independent components; **elements** belong to a block.
- **Modifiers** express variants or states and stay alongside their base classes.
- Prefer simple class selectors and semantic names over deep nesting or styling-specific names.
- BEM improves maintainability but does not replace semantic HTML, accessibility, or understanding the cascade.
