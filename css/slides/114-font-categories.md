# Typeface, Font & Font Categories

<div>
  <img src="/images/typography-font-families.svg" alt="Serif, sans-serif and monospace font samples" class="block mx-auto w-full" style="max-height: 32vh; object-fit: contain;" />
</div>

- A **typeface** is a design family.
- A font represents a particular implementation or style.
- Script and display faces can suit short decorative text.
- Choose fonts for their purpose, not rigid rules.
