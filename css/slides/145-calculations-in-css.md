# Calculations in CSS

```css
:root {
  --space: 0.5rem;
  --color-primary: #125BD4;

  --primary-light: color-mix(in oklab, var(--color-primary) 60%, white);
  --primary-dark: color-mix(in oklab, var(--color-primary) 80%, black);
}

.task-card {
  padding: calc(var(--space) * 2);
  background: var(--primary-light);
  border-color: var(--primary-dark);
}
```

- `calc()` computes **lengths**: one base unit becomes a spacing scale.
- `color-mix()` computes **colors**: tints and shades derive from one base color.
- Change `--color-primary` once — the whole palette follows.
