- **Positioning** controls offsets and containing blocks; absolute and fixed boxes leave normal flow.
- **Flexbox** distributes items along a main axis and aligns them along a cross axis.
- **Grid** coordinates rows and columns using tracks, lines and areas.
- Use **both** layout systems together; preserve semantic DOM order.
- Test narrow widths, text growth, scrolling and keyboard focus.
