# Exercise 14 — Visual Design

1. Choose and document a color scheme; apply it with your typeface.
2. Refine typography, hierarchy and text spacing.
3. Investigate self-hosted web fonts and fallback.
4. Style backgrounds, component boundaries and controls consistently.
5. Verify contrast and the existing responsive layouts.
