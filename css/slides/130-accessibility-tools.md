# Accessibility Testing Tools

| Tool | Use |
| --- | --- |
| [Lighthouse](https://developer.chrome.com/docs/devtools/accessibility/reference) | Automated accessibility report |
| Browser DevTools | Contrast, accessible names, accessibility tree |
| [Accessibility Insights for Web](https://accessibilityinsights.io/docs/web/getstarted/fastpass/) | Automated checks and guided tab-stop test |
| [WAVE](https://wave.webaim.org/extension/) / [axe DevTools](https://www.deque.com/axe/devtools/) | Alternative browser extensions |

**A perfect automated score does not prove accessibility.**
