# Exercise 05 — Normal flow and floats

1. Start from the **completed Exercise 04** Task Manager.
2. Open the provided **Task Manager task card** and observe the initial **normal flow**.
3. Use `float: left` to position the task icon beside the description.
4. Add `12px` of space between the icon and the text using `margin-right`.
5. Apply `clear: both` to position the **Mark as done** button below the floated icon.
6. Change the icon to `float: right`, adjust the margin, and verify that `clear: both` still works.
