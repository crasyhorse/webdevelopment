- **Combinators** express descendant, child and sibling relationships.
- **Pseudo-classes** describe state or structure; **pseudo-elements** target parts of elements or generate decorative content.
- The **cascade** compares declarations by origin, importance, layer, specificity and final tie-breakers.
- **Specificity** uses `ID-CLASS-ELEMENT` weights; `!important` changes cascade priority rather than selector weight.
- **Inheritance** passes some property values to children; `inherit`, `initial` and `unset` give explicit control.
