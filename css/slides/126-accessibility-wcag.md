# Web Accessibility & WCAG

- **Perceivable:** information can be perceived.
- **Operable:** interfaces can be operated.
- **Understandable:** content and interactions are understandable.
- **Robust:** content works with user agents and assistive technology.

[WCAG 2.2](https://www.w3.org/TR/WCAG22/) — Levels A, AA and AAA; aim for AA.
