- **Media queries** conditionally change layouts based on media features.
- Choose breakpoints based on content needs, not device models.
- Flexbox and Grid can adapt intrinsically without explicit breakpoints.
- **CSS math functions** bound fluid sizes and spacing.
- **Container queries** adapt reusable components to local space.
- Test resizing, overflow, zoom and keyboard navigation.
