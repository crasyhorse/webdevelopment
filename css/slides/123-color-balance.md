# Applying Colors to an Interface

<div>
  <img src="/images/color-interface-balance.svg" alt="Task Manager with neutral surfaces, primary actions and semantic accents; approximate 60–30–10 heuristic" class="block mx-auto w-full" style="max-height: 40vh; object-fit: contain;" />
</div>

- Let one color or neutral group dominate.
- Use supporting colors and accents to establish hierarchy.
- The 60–30–10 rule is a heuristic, not a pixel-counting requirement.
