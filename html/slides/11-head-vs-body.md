# Metadata vs. visible content

::left::

### `<head>` — Metadata

<div class="mt-5"></div>

- `<title>` — browser tab title and bookmarks
- `<meta charset="utf-8">` — character encoding
- `<meta name="viewport" ...>` — viewport configuration
- `<link rel="stylesheet" ...>` — external stylesheet

::right::
### `<body>` — Document content

<div class="mt-5"></div>

- `<h1>` / `<p>` — headings and paragraphs
- `<a>` / `<button>` — links and interactive controls
- `<nav>` / `<main>` — semantic page structure
