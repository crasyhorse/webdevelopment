# Make content and controls meaningful

- **Headings:** `<h1>`–`<h6>` describe document hierarchy.
- **Lists:** `<ul>` / `<ol>` with `<li>` communicate grouped items.
- **Links:** `<a href="...">` navigates somewhere.
- **Buttons:** `<button>` performs an action.
- **Forms:** `<label>` gives inputs a discoverable name.
