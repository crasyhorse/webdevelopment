# Live coding: Inspect and improve accessibility

1. Navigate the Task Manager using **Tab**, **Enter**, and **Space**.
2. Inspect computed roles and accessible names in DevTools.
3. Name the task section using `aria-labelledby`.
4. Add a helpful input description with `aria-describedby`.
5. Inspect the result again.
