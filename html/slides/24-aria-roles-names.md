# Roles, names, states

- **Role:** what the element is (`button`, `navigation`, `status`).
- **Name:** how users identify it (`Tasks`, `Add task`).
- **State:** what is currently true (`aria-expanded="false"`).
- Native HTML supplies many roles and names automatically.
