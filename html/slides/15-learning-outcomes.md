# Learning Outcomes

I will ...

1. learn how to choose **semantic HTML elements** based on meaning rather than appearance.
2. become familiar with **semantic landmarks** and how they organize a page.
3. discover when to use **section**, **article**, or a neutral container.
4. explore how semantic elements support **accessibility and automated testing**.
